### `Ledger.Spec.plan`

The rules of §3, with errors checked in the order the table lists them. `look n` is
the balance of account `n`, or nothing if there is no such account.
* `open n`: bad name; account exists; otherwise create `n` with 0 and answer OK.
* `deposit n a`: bad name; bad amount; unknown account; new balance over the maximum; otherwise
  set the new balance and answer it.
* `withdraw n a`: bad name; bad amount; unknown account; balance below `a`; otherwise set the new
  balance and answer it.
* `transfer f t a`: bad name (either); same account; bad amount; unknown `f`; unknown `t`; `f`'s
  balance below `a`; `t`'s new balance over the maximum; otherwise set both balances in one step
  and answer OK.
* `balance n`: bad name; unknown account; otherwise answer the balance.
* `accounts`, `total`: answer from the whole ledger.

```lean
Ledger.Spec.plan (look : LeanKV.Spec.Bytes → Option Nat) : Ledger.Spec.LCmd LeanKV.Spec.Bytes → Ledger.Spec.Plan
```

### `Ledger.Spec.plan_write_cases`

**The successful writes, exactly.** A command makes a write plan only in these four
cases, and then sets exactly these balances and gives exactly this answer:
* `open n` with a valid name and no account `n`: set `n` to 0, answer OK;
* `deposit n a` with a valid name and amount, account `n` holding `b`, and `b + a ≤ maxBalance`:
  set `n` to `b + a`, answer that balance;
* `withdraw n a` with a valid name and amount, account `n` holding `b ≥ a`: set `n` to `b − a`,
  answer that balance;
* `transfer f t a` with two valid, different names, a valid amount, `f` holding `bf ≥ a` and `t`
  holding `bt` with `bt + a ≤ maxBalance`: set `f` to `bf − a` and `t` to `bt + a`, answer OK.

*Status:* Proven

```lean
Ledger.Spec.plan_write_cases {look : LeanKV.Spec.Bytes → Option Nat} {c : Ledger.Spec.LCmd LeanKV.Spec.Bytes}
  {ups : List (LeanKV.Spec.Bytes × Nat)} {r : Ledger.Spec.LResp}
  (h : Ledger.Spec.plan look c = Ledger.Spec.Plan.write ups r) :
  (∃ n,
      c = Ledger.Spec.LCmd.openAccount n ∧
        Ledger.Spec.validName n = true ∧ look n = none ∧ ups = [(n, 0)] ∧ r = Ledger.Spec.LResp.ok) ∨
    (∃ n a b,
        c = Ledger.Spec.LCmd.deposit n a ∧
          Ledger.Spec.validName n = true ∧
            Ledger.Spec.validAmount a = true ∧
              look n = some b ∧
                b + a ≤ Ledger.Spec.maxBalance ∧ ups = [(n, b + a)] ∧ r = Ledger.Spec.LResp.balance (b + a)) ∨
      (∃ n a b,
          c = Ledger.Spec.LCmd.withdraw n a ∧
            Ledger.Spec.validName n = true ∧
              Ledger.Spec.validAmount a = true ∧
                look n = some b ∧ a ≤ b ∧ ups = [(n, b - a)] ∧ r = Ledger.Spec.LResp.balance (b - a)) ∨
        ∃ f t a bf bt,
          c = Ledger.Spec.LCmd.transfer f t a ∧
            Ledger.Spec.validName f = true ∧
              Ledger.Spec.validName t = true ∧
                f ≠ t ∧
                  Ledger.Spec.validAmount a = true ∧
                    look f = some bf ∧
                      look t = some bt ∧
                        a ≤ bf ∧
                          bt + a ≤ Ledger.Spec.maxBalance ∧ ups = [(f, bf - a), (t, bt + a)] ∧ r = Ledger.Spec.LResp.ok
```
